# NUGUNA V18 UI 리뉴얼 검토

기준: `work/static-beta`의 V18 정적 베타. 외부 백엔드·V19 코드는 사용하지 않는다. 현재 구현은 프레임워크 교체 없이 기존 HTML, CSS, JavaScript와 localStorage를 사용한다.

## 기존 주요 화면 및 보존 항목

- 공개 홈페이지: 상품 목록, 상품 탐색·검색, 가입·로그인, 등급 안내, 브랜드 센터, 관리자 진입, 판매 링크 미리보기.
- 판매자: 회원가입·승인 시연, 대시보드, 판매 가능 상품, 판매 링크 발급·공유, 주문·정산, 판매 등급.
- 기업회원: 가입·입점, 상품·옵션 등록, 승인 상태, 주문·배송, 엑셀 다운로드·운송장 일괄 등록, 정산 시연.
- 관리자: 입점·상품 승인 및 반려, 판매자·등급, 주문·환불, 정산, 분석, 판매 링크, 배송 현황, 시뮬레이션.
- 구매자: 판매 링크 진입, 상품·옵션·수량, 모의 주문과 결제, 비회원 모의 인증·주문조회, 구매확정 및 취소·반품 신청.

## 디자인 적용

`nuguna_beta/renewal.css`에 색상, 입력창, 버튼, 카드, 표, 판매자·기업회원 메뉴, 관리자 및 구매자 화면의 공통 스타일을 모았다. 판매자 대시보드는 기존 상품과 현 브라우저의 시연 기록을 표시한다. 판매자·기업회원·관리자 메뉴는 PC에서 접을 수 있고 모바일에서는 가로로 넘길 수 있다. 이미지와 주문 금액, 등급 조건, 저장 키, URL 및 데이터 구조는 기존 로직을 사용한다. 신규 화면에 그래프나 지표가 없을 때 임의의 실적을 표시하지 않는다.

## 검증 및 제한

- `npm test`, `npm run build`.
- PC 1440px / 모바일 390px: 상품 등록·승인, 개인 판매 링크, 옵션 선택, 모의 결제, 비회원 주문조회, 주문 취소 및 관리자 배송 처리.
- PC / 모바일: 실제 xlsx 다운로드 및 재업로드, 브랜드 범위 검증, 중복·오류 처리, 구매자 화면의 송장 표시.
- PC / 모바일: 판매자·기업회원·관리자 탐색, 관리자 메뉴 접기·펼치기.
- 브라우저 localStorage에만 보관되는 시연 데이터와 모의 인증·결제의 기존 제약은 유지된다. 실제 계정·결제·공유 데이터는 제공하지 않는다.
- Pretendard는 브라우저에 이미 설치되어 있는 경우 우선 적용하고, 없으면 시스템 한글 폰트로 대체한다. 정적 베타는 외부 폰트 API에 의존하지 않는다.
