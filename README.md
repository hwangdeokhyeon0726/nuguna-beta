# NUGUNA 정적 베타

기존 NUGUNA 시연 화면을 HTML, CSS, JavaScript와 브라우저 저장소로 실행합니다. Node.js가 설치되어 있다면 추가 패키지 설치 없이 빌드할 수 있습니다.

```sh
npm run build
```

생성된 `dist/` 폴더 전체를 정적 사이트 호스팅의 게시 폴더로 사용합니다. 개발 중에는 다음 명령으로 `http://localhost:8000/`에서 확인할 수 있습니다.

```sh
python3 -m http.server 8000 --directory dist
```

상품, 회원, 링크 및 주문은 현재 브라우저에만 저장되는 가상 데이터입니다. 다른 기기 또는 다른 주소로 공유되지 않습니다. 모의 계정·가상 인증·모의 결제를 사용하며 실제 개인정보, 신분증, 계좌정보를 입력하지 마세요. 브라우저 데이터를 지우면 시연 기록도 사라질 수 있습니다. 관리자 화면에서 시연 데이터 JSON을 내보낼 수 있습니다.

상품 링크는 같은 사이트 경로에서 `#r/링크ID`로 동작합니다. 브라우저 주소가 바뀌면 기존 Netlify 주소는 새 호스팅 주소로 자동 전환되지 않습니다. 또한 다른 브라우저에서 생성된 개인 링크는 공유 저장소가 없으므로 인식되지 않습니다.

이 프로젝트는 비공개 테스트를 전제로 합니다. 저장소 공개 또는 접근 제한 없는 정적 호스팅은 설정하기 전에 공개 범위를 확인해야 합니다. 배포 환경의 민감한 인증정보는 저장소에 넣지 마세요.
