# NUGUNA 정적 베타

기존 NUGUNA 시연 화면을 HTML, CSS, JavaScript와 브라우저 저장소로 실행합니다. Node.js가 설치되어 있다면 추가 패키지 설치 없이 빌드할 수 있습니다.

```sh
npm run build
```

생성된 `dist/` 폴더 전체를 정적 사이트 호스팅의 게시 폴더로 사용합니다. 개발 중에는 다음 명령으로 `http://localhost:8000/`에서 확인할 수 있습니다.

```sh
python3 -m http.server 8000 --directory dist
```

상품, 회원, 링크 및 주문은 현재 브라우저에만 저장되는 가상 데이터입니다. 다른 기기 또는 다른 주소로 공유되지 않습니다. 모의 계정·가상 인증·모의 결제를 사용하며 실제 개인정보, 신분증, 계좌정보를 입력하지 마세요. 브라우저 데이터를 지우면 시연 기록도 사라질 수 있습니다. 관리자 화면에서 시연 데이터 JSON을 내보낼 수 있습니다.

상품 링크는 같은 사이트 경로에서 `#r/링크ID`로 동작합니다. 브라우저 주소가 바뀌면 기존 Netlify 주소는 새 호스팅 주소로 자동 전환되지 않습니다. 또한 다른 브라우저에서 생성된 개인 링크는 공유 저장소가 없으므로 인식되지 않습니다.

## 주문·배송 엑셀 시연

기업회원 대시보드의 `주문·배송관리`에서 가상 신규 주문을 만들거나 구매자 화면에서 모의 주문을 생성할 수 있습니다. 신규 주문 엑셀을 다운로드하고 주문번호는 바꾸지 않은 채 `택배사`와 `운송장번호`를 입력해 `.xlsx`로 저장한 후 다시 업로드하세요. 정상 행만 반영되며, 오류와 중복은 주문번호 및 사유와 함께 표시됩니다. 운송장 등록은 배송중이나 배송완료로 자동 변경되지 않습니다.

운송장번호는 앞자리 0이 손실되지 않도록 텍스트로 입력합니다. 시연용 고정 수령인 정보만 엑셀에 포함되며 실제 고객 정보는 사용하지 않습니다. 브랜드 권한 검사는 브라우저 내 시연용이므로 실제 보안 경계가 아닙니다. 데이터는 같은 브라우저에서만 공유됩니다.

엑셀 파일 처리는 `nuguna_beta/vendor/`에 함께 제공되는 SheetJS 0.20.3을 사용합니다. 라이선스는 같은 폴더의 `SHEETJS-LICENSE.txt`를 참고하세요. 앱 실행 시 CDN이나 택배·메시지 API에는 접속하지 않습니다. 공개 승인 상품의 조회에는 Supabase API를 사용합니다. 핵심 엑셀 검증은 `npm test`로 실행합니다.

이 프로젝트는 비공개 테스트를 전제로 합니다. 저장소 공개 또는 접근 제한 없는 정적 호스팅은 설정하기 전에 공개 범위를 확인해야 합니다. 배포 환경의 민감한 인증정보는 저장소에 넣지 마세요.

## 상품 재고와 SKU 시연

기업회원은 신규 상품에 정상가와 판매가, 옵션별 추가금액·SKU·초도수량을 입력할 수 있습니다. 비어 있는 옵션 SKU는 자동 생성하고 같은 브랜드 내 중복 입력을 막습니다. 기존 상품은 재고를 명시적으로 설정하기 전까지 `미설정`으로 표시합니다. 등록 후 `재고·SKU 수정`에서 변경하며 최근 수량 변경 기록을 볼 수 있습니다. 가격은 기업회원이 변경을 요청하고 관리자가 승인해야 적용됩니다.

재고와 주문은 동일 브라우저의 localStorage에만 저장되는 모의 데이터입니다. 모의 결제 성공 시 설정된 재고를 차감하고, 실패 시 차감하지 않습니다. 재고가 0이면 구매 버튼이 비활성화되며, 관리자가 판매중지한 상품은 재고를 보충해도 판매중지 상태를 유지합니다. 취소·반품 후 재고는 자동으로 복원되지 않으며, 브랜드가 출고 여부를 확인하고 직접 조정해야 합니다.

결제 중 재고 예약·만료, 서버 기준 원자적 차감, 여러 탭이나 기기의 동시 주문 방지 및 기기 간 동기화는 구현되어 있지 않습니다. 정식 재고 운영에는 서버·데이터베이스, 인증과 원자적 트랜잭션이 필요합니다. 실제 고객·실재고 관리에 사용하지 마세요.

## 일반구매·공동구매 시연

기업회원이 상품 등록 시 공동구매를 함께 신청하거나 기존 상품에서 개설을 요청할 수 있습니다. 관리자는 상품과 공동구매를 각각 승인합니다. 승인된 진행 중 캠페인은 메인 화면과 해당 상품의 구매 화면에서 확인할 수 있습니다. 구매자는 같은 상품에서 일반구매 또는 공동구매를 선택하고 모의 결제할 수 있습니다. 관리자 공동구매 관리의 시간 진행 기능으로 마감을 시연할 수 있습니다.

공동구매 모의 주문은 성공하기 전까지 배송과 정산을 보류합니다. 시연 캠페인이 마감돼 목표에 미달하면 해당 공동구매 주문만 모의 환불하고 예약된 모의 재고를 복원합니다. 브라우저를 열거나 관련 화면을 사용할 때 마감 처리가 실행됩니다. 브라우저가 닫힌 동안 서버에서 자동으로 처리되는 기능은 없습니다. 일반구매 주문에는 영향을 주지 않습니다.

추천 귀속은 이 브라우저에서 마지막 유효 클릭 후 24시간 동안 시연하며 다른 상품에도 적용됩니다. 실제 고객의 본인 구매 판별, 조작 방지, 기기 간 귀속 및 서버 시각 검증은 구현되어 있지 않습니다. 결제, 환불, 재고 예약과 동시 주문 방지 또한 실제 서버·PG 없이 보장할 수 없습니다. 실제 결제나 환불이 발생하지 않으며 여러 기기에서 시연 데이터를 공유할 수 없습니다.

## Supabase 승인 상품 조회

홈페이지의 서버 상품 영역은 Supabase의 공개 승인 상품을 읽기 전용으로 조회합니다. 조회 실패와 승인 상품이 없는 상태는 구분하여 표시합니다. 서버 상품은 현재 주문, 판매 링크 및 기존 브라우저 상품과 연결되지 않습니다. 회원, 주문, 재고, 공동구매는 기존 브라우저 시연 데이터이며 여러 기기에서 공유되지 않습니다. 실제 개인정보를 사용하지 마세요.
